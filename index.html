    How the Browser Renders This Page

    HTML and CSS text become pixels through this exact pipeline — the same one that just drew this card.

    01

    HTML → Parsing

    The browser reads raw HTML bytes and converts them into characters, then tags.

    02

    Tokenization

    Characters are grouped into tokens: start tags, end tags, attribute names/values.

    03

    DOM Tree

    Tokens become nodes; nodes are linked by parent/child relationships into the DOM tree.

    04

    CSS → CSSOM Tree

    Stylesheets are parsed the same way and built into the CSSOM — a tree of computed styles.

    05

    Render Tree

    DOM + CSSOM are combined; nodes with display:none are excluded.

    06

    Layout

    The browser computes exact size and position for every render-tree box.

    07

    Paint

    Pixels are filled in: color, borders, shadows, text — onto layers.

    08

    Composite

    Layers are merged by the compositor thread and drawn to the screen.
